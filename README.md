# 投资复利计算器

原生 HTML / CSS / JavaScript 实现的投资规划工具，无后端、无前端构建步骤，支持固定收益预测、真实月度历史回测、目标反推、通胀折算、方案比较及 CSV 导出。

## 在线使用

**[点击打开投资复利计算器网页版](https://jalhao.github.io/InterestCalculator/)**

通过 GitHub Pages 部署，点击链接即可在浏览器中使用，无需下载或安装。

## 本地运行

```bash
cd InterestCalculator
python3 -m http.server 8000 --bind 127.0.0.1
```

用浏览器访问本地静态服务。直接打开 `index.html` 仍可使用固定预测和内置年度示例；月度行情加载需要 HTTP 服务。

## 功能与计算口径

- **固定预测**：年化收益按 `(1 + 年化收益率)^(1/12) - 1` 换算为等效月收益，提供保守 / 基准 / 乐观三个假设。这些是敏感性情景，不是概率区间。
- **投入**：按月 / 按年，期初 / 期末。年度投入以投资开始月份为起点，每 12 个月一周期。区间末尾不足一年的周期，年度期末定投尚未到期，因此不会提前计入。
- **目标反推**：支持未来名义金额和今天购买力两种目标。线性求解后重新模拟验证，不可达或超出单次 1 万亿元上限时明确提示。首次达标按月检查；历史回测仅描述样本，不预测未来。
- **通胀**：终值和各笔投入分别按发生月份折现到投资起点，再计算实际累计收益。未来投入金额默认固定，不随通胀上调。
- **收益指标**：累计收益率是累计收益 / 累计投入；资金加权年化使用按投入月份计算的周期 IRR。指数样本年化是指数点位的 CAGR，三者不能直接视为同一指标。
- **图表 / 明细**：按每 12 个月汇总，保留末尾不足一年的区间。目标线可关闭，支持鼠标、触摸及方向键 / Home / End / Escape 操作。
- **方案**：自动记住参数；最多保存 4 个方案并列展示终值、投入、购买力和年化。方案仅保存在当前浏览器，可删除；URL 分享只携带计算参数。不同方案应保持投入、期限和数据口径一致后比较。
- **导出**：CSV 包含明细表及后附的参数、实际起止区间、行情抓取日期和收益口径。

金额字段按元取整。初始本金及单次投入上限为 1 万亿元，目标输入上限为 1000 万亿元；这些范围用于边界保护，不代表合理投资规模。计算采用 JavaScript 浮点数，展示金额四舍五入，结果属于模型估算。

## 动态历史回测

支持 **标普 500（`^GSPC`）** 和 **纳斯达克 100（`^NDX`，不是纳斯达克综合指数）**。

1. 更新脚本从 Yahoo Finance chart 接口获取自 1985 年起可用的日收盘点位，以纽约交易日期归组，取每个月最后一个可用收盘点位。
2. 只发布已完整结束的月份，排除本月；相邻月末点位计算真实月收益，取代原来按年度收益平滑到每个月的近似方式。
3. 首个点位作为基准，用户从其后一个月开始选择投资月份。起始月期初投入对应上月月末点位，期末投入对应当月月末点位。
4. 同源 `data/market-data.json` 供网页加载，浏览器不直接请求 Yahoo，因此不依赖跨域许可，也无需向浏览器暴露密钥。
5. 页面自动加载快照，可手动刷新已发布文件；验证通过后缓存。刷新失败保留已验证数据，无可用数据时明确显示年度示例近似。数据滞后会提示，不把缓存冒充最新行情。

**数据口径**：美元价格指数，不含分红再投资、汇率变动、费用及税费。界面中的人民币符号只表示统一记账单位，不代表美元指数已换算成人民币收益。月度定投仍不模拟月内实际成交路径或交易日。

Yahoo Finance chart 是非保证可用性的公开接口，可能限流、变更或拒绝请求。数据源和抓取时间可追溯不代表数据一定无误，使用前应与独立来源核对。更新脚本不绕过 TLS 验证，也不会用假数据填补缺失月份。

沪深 300 暂保留 2010—2024 年内置年度示例；旧的美股年度示例也可手动选择。它们没有附可核验来源，仅用于演示，页面明确标记为近似，不作为精确回测。

### 首次抓取与自动更新

```bash
python3 scripts/update_market_data.py
```

脚本仅使用 Python 3.12 标准库，需要允许 HTTPS 访问 `query1.finance.yahoo.com`，不需要 API 密钥。成功后写入两个标的的完整数据；任一标的失败、缺月、无效点位、最新完整月份缺失或历史倒退都会中止，不覆盖原有文件。

初始提交中的 `data/market-data.json` 是**空占位文件**，不是历史行情。第一次真实抓取成功后，才可使用真实月度回测。测试中的合成行情不会写入该文件。

`.github/workflows/update-market-data.yml` 提供：

- 更新脚本或更新工作流推送到 `main` 时自动运行（含首次推送）。
- `workflow_dispatch` 手动运行。
- 每周二至周六北京时间 **09:30**（UTC 01:30）执行，更新截至最新完整月份的数据。它不是盘中实时行情服务。
- 抓取成功后提交数据文件，再显式调用 Pages 部署工作流。使用 `GITHUB_TOKEN` 提交通常不会触发另一条 push 工作流，因此这里不依赖该行为。
- 更新失败保留上一份数据，GitHub Actions 显示失败供排查。定时任务可能延迟；页面仍以数据日期判断新旧。

将修改推送到主分支后，在 GitHub 仓库中：

1. 确认 Actions 可运行，允许自动更新工作流写入仓库；分支保护或组织策略可能要求另行配置。
2. 在 **Settings → Pages → Source** 选择 **GitHub Actions**。
3. 在 **Actions → Update market data → Run workflow** 首次生成行情并部署。
4. 确认更新、数据提交和部署均成功，再在网页中检查最新完整月份及数据来源。

fork 仓库或长期无活动的仓库可能需要重新启用定时任务。工作流默认发布 `main` 分支；其他分支需要同步调整部署配置。网页上的“刷新已发布行情”只重新读取快照，不会触发 GitHub 工作流。

## 测试

核心计算和更新脚本测试无需第三方依赖：

```bash
node --test tests/engine.test.js
python3 -m unittest discover -s tests -p 'test_*.py'
```

浏览器功能测试需要静态服务和 Playwright：

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium
CHROMIUM_EXECUTABLE='' python3 tests/browser_smoke.py
```

已有系统 Chromium 时可直接执行 `python3 tests/browser_smoke.py`，默认使用 `/usr/bin/chromium`。浏览器测试通过拦截请求分别验证断网降级和合成月度路径，不依赖当天行情。测试覆盖小数编辑、输入边界、计算公式、通胀基准、目标反推、CSV、持久化 / 分享、月度区间、缓存恢复和移动端布局。

`.github/workflows/tests.yml` 在 push / pull request 时执行计算、更新脚本和浏览器测试。

## 文件结构

```text
index.html / styles.css     页面与响应式布局
engine.js                   纯计算、目标求解与行情校验（浏览器 / Node 共用）
historical-data.js          旧年度示例数据
app.js                      页面计算协调、图表与交互
app-extras.js               行情加载 / 缓存、参数持久化和方案分享
data/market-data.json       定时生成的月末点位快照
scripts/update_market_data.py
tests/                     计算、数据管线与浏览器测试
.github/workflows/          测试、更新和 Pages 部署
```

结果用于投资教育和假设分析，不代表未来收益。
